# Virtual Radio Mic (擬似スピーカー＆音声ミキサー)

イベント会場や校内放送、アナウンス現場などで、端末（スマートフォン、タブレット、PC）をスピーカーに接続して「簡易マイク＆ラジオPAミキサー」として活用できるWebアプリケーションです。

---

## 🎙️ 主な機能

- **リアルタイム・低遅延パススルー**: Web Audio API による最小レイテンシでの音声出力
- **ノイズキャンセリング（雑音・残響カット）**: 低性能端末の全指向性マイク向け。強さは OFF / 弱 / 標準 / 強
  - 適応ノイズゲート: 雑音レベルを自動で推定し、話していない間の周りの音を下げる
  - 残響テール抑制: 声の後に残る部屋の響きを、子音を残しつつ短くする
  - 声向け EQ（低域の響き・こもり・高域ヒスのカット）＋ ブラウザ内蔵ノイズ抑制（対応ブラウザのみ）
  - 吹かれ防止（80Hz ローカット）・音割れ防止リミッター
  - すべてブラウザ内（AudioWorklet）で処理。遅延の追加なし、負荷はごくわずか
- **トークモード**:
  - **トグルモード**: タップでマイクON/OFF
  - **PTT (Push-to-Talk) モード**: 押している間だけ発声
- **ラジオ・音声エフェクト (FX)**:
  - **エコー (ディレイ)**: やまびこ反復 ＋ 深さ調整スライダー
  - **AMラジオ / 無線**: レトロなローファイ音声
  - **ロボットボイス**: 65Hz変調による機械声
  - **スタジオ残響**: 空間の広がりを演出
- **マイクチェック機能**: Web Audio API ネイティブ PCM 直接録音によるテスト録音＆即時プレビュー再生
- **入出力オーディオ設定**: 入力マイクおよび出力先スピーカー/イヤホンの選択、出力方式（標準 / 互換）の切り替え
- **音量＆音質詳細ミキサー**: マイク増幅ゲイン（0〜300%）、マスター音量、3バンドEQ
- **完全オフライン＆PWA対応**: ネット環境のない会場でもオフラインで使用可能

---

## 🛠️ 使い方

1. 端末のイヤホン端子（または変換アダプタ）からオーディオケーブルで会場スピーカーの AUX / MIC IN 端子に接続します。
2. アプリを開きます。
3. 必要に応じて「マイクチェック」でテスト発声を行い、聞こえ具合を確認します。
4. トークモードやエコーなどのエフェクトを設定し、マイクボタンをタップまたは長押しして放送を開始します。
5. 声に響きや周りの音が混ざる場合は「ノイズキャンセリング」を「標準」または「強」にし、マイクを口元 10〜20cm に近づけてマイク増幅ゲインを下げてください。
